## Non-Benchmarkable Notes

- Visual route-styling "correctness" (does the motorbike-class route look visually distinct from the car-class route) is validated qualitatively via screenshot/DOM paint-property inspection in `evidence.md`, not as a numeric benchmark beyond the "distinct paint variants" count above.
- Dispatcher account validation (login success with a real account from the provided Excel sheet) is a pass/fail check recorded in `evidence.md`, not a benchmark metric.
- Full Docker build/run success is a pass/fail gate recorded in `evidence.md` (`Pn-C`), not a benchmark metric, unless a build-time/size regression is specifically observed, in which case it would be added here.
- GPS satellite positioning accuracy (document's Table 4.3) is explicitly NOT benchmarked with a fabricated or simulated number; `P9-A` replaces it with a spec-based textual statement in `evidence.md`/the corrected document, not a benchmark table row, because it cannot be measured without real device hardware and real-world field conditions.
- The document's original "30 field measurement points in Cần Thơ" framing is not reproduced in any form; this plan's `P9` benchmarks are explicitly against this machine's Docker Compose stack, not field conditions, and are labeled as such wherever they are cited.
